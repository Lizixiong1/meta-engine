# Introduction

Welcome to Meta Engine!

Meta Engine is a framework-agnostic meta-driven engine for enterprise-grade complex UI systems. It allows you to build forms, tables, CRUD operations, search functionality, and page orchestration using metadata-driven configuration.

## What is Meta Engine?

Meta Engine is designed to:

- **Decouple UI from business logic** using metadata
- **Support multiple frameworks** through adapters
- **Provide enterprise-grade capabilities** like permissions,联动, and state management
- **Be extensible** to support custom components and behaviors

## Why use Meta Engine?

- **Consistency**: Ensure consistent UI and behavior across different projects
- **Productivity**: Reduce boilerplate code and speed up development
- **Flexibility**: Adapt to different frameworks and component libraries
- **Maintainability**: Centralize configuration and logic

## Getting Started

To get started with Meta Engine, you'll need to:

1. Install the core package
2. Set up an adapter for your framework and component library
3. Define your metadata configuration
4. Render components using the engine
